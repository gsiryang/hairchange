# 3D 示例素材说明

本目录中的人体基础网格、人体形变、皮肤贴图、眼睛贴图和三款发型网格来自 MakeHuman Community 的官方系统素材。

- 来源：https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- MakeHuman 项目：https://github.com/makehumancommunity/makehuman
- 资产许可：CC0（可用于商业原型）
- Three.js 与 OBJLoader：MIT License

`head.obj` 使用 MakeHuman 官方基础人物网格，皮肤使用官方年轻亚洲男性纹理。眼睛使用 MakeHuman 官方高精度眼球网格与贴图。

这些资产仅用于演示三维旋转、侧脸观察和发型切换，不代表照片重建结果。
