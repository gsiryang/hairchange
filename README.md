# 第一阶段本地原型

## 当前默认建模界面

按用户最新要求恢复第一版通用头模（studio.html），建模页不再加载参考头像或其拟合头模。原资源仅保留在工程中。

三款发型提供「头发长度」60–150% 与「头发蓬松度」0–100% 滑条，即时改变发束尺寸及位置，保留头部与头皮形状。切换发型沿用滑条值，保存对比图会记录两项参数。这些百分比是示例造型参数，不代表真实厘米数。

以下参考头像三维实现记录为历史版本，不是当前默认页面。

## 参考头像三维试戴

建模页当前默认使用 `web/avatar3d.html`，不是照片平面展示。Python + MediaPipe FaceMesh 从生成的参考头像估计 468 个人脸关键点，再补齐眼睛和唇部孔洞，生成 471 顶点、934 三角面的人脸网格；照片作为 UV 纹理。未观测的后脑、耳朵、颈部为程序化补全。深度是单图估计，不能作为精确真人扫描或身份一致性保证。

Three.js 支持拖动旋转、双指／滚轮缩放、正／斜／侧／背视角，纹理短发／自然侧分／中分刘海三款独立立体发型、发色、网格查看及当前视角保存。发型为参数化体积网格和三维发丝线条，不是商业级发丝资产。纹理包含原图光照，侧脸和脸头交界仍可能有视觉瑕疵。

资源：`web/assets/reference-face.json`、`avatar-reference-v1.png`。标准人脸拓扑来自 Google MediaPipe，许可保存在 `MEDIAPIPE-LICENSE.txt`。再生成脚本为 `build_reference_mesh.py`，工具安装在项目 `.runtime`；Windows 含中文路径时可用 `FAJIAN_RUNTIME` 指向 ASCII 路径的依赖副本。当前已生成静态网格，正常启动网页无需安装这些建模依赖。

原始图片预览已退出建模页默认流程；旧交互示例仍保留在 studio.html，未删除文件。实际浏览器视觉验收仍受当前浏览器工具故障限制。

## 手机界面更新

### 发布与管理

底部导航中央增加「＋ 发布」，位于建模和理发店之间。用户可以选择最多四张 JPG/PNG/WebP 图片（单张不超过 10 MB，保存前压缩），填写标题、正文并选择发型／妆容／cosplay 分类。第一张图片作为封面。

「我 → 我的帖子」支持已发布／草稿筛选、查看、编辑、删除。已发布内容进入本地首页，草稿不会进入首页。删除需要确认，删除后同步清理当前会话的点赞、收藏引用。未提交的编辑在页面内切换时暂存在内存，刷新会丢失；需点击存草稿或发布以持久保存。

帖子及其图片存入此浏览器 localStorage，刷新后保留；不同设备、浏览器、访问地址之间不会同步，清除浏览器数据会丢失。没有上传到服务器，也未向其他用户公开。达到存储容量时会提示失败并保留编辑内容。损坏的本地数据不会被静默覆盖。

实现：web/publishing.js。检查命令：`node tests/publishing.test.cjs`，覆盖发布、刷新持久化、编辑、草稿隔离、输入转义、校验、存储失败、删除和原页面回归。图片解码压缩与实际布局尚未完成浏览器验收，沿用此前浏览器工具不可用的限制。

首页已改为「发间」手机网页，底部导航包含首页、建模、理发店、我。

- 首页：双列分享流，发型／妆容／cosplay 分类、搜索、帖子详情、点赞与收藏。
- 理发店：店铺搜索与排序、店铺评分和评价、地址复制、理发师列表。
- 理发师详情：所属店铺、擅长风格、作品示意、针对该理发师的评价。
- 我：本次会话的收藏与点赞列表、隐私说明。
- 建模：嵌入原有试戴示例，真实重建仍未实现。

店铺、地址、示例用户、作品归属、预置帖子及评价均为演示数据；Unsplash 远程图片只作界面配图，需要联网加载，不代表真实店铺或用户。当前无定位、登录、预约、公开发帖与评论接口，本地发帖已支持。页面适配手机，电脑端居中显示手机宽度。

新界面文件：web/mobile.js、web/mobile.css。旧试戴入口保留在 web/studio.html、web/studio.css。

验证：JavaScript 语法检查通过；使用模拟页面容器验证八个路由、分类筛选与收藏列表。浏览器工具因运行环境限制无法初始化，尚未完成实际浏览器视觉验收。

这是商业产品的交互与三维展示起点，不是完整的照片重建产品。

## 启动

在此目录运行 `python app.py`，然后打开 http://127.0.0.1:8765 。Python 3.8 及以上即可，无需 pip 安装，三维库已存入本地。

手机体验：电脑和手机连接同一个可信 Wi-Fi，运行 `python app.py --host 0.0.0.0`，在手机浏览器打开 `http://电脑局域网IP:8765`。必要时允许系统防火墙在私人网络接入。不要将开发服务器直接暴露到公网。

## 尚未实现 / 验收边界

照片不会改变三维模型。头模与发型都是简化几何示例，不能用于判断真人适配度。尚无完整头部重建、去除原发型、逼真发丝、账户、支付或原生安装包。刷新页面会清除照片与对比记录，重要对比图请下载。

## 下一阶段：个人头模技术验证

1. 采集获得本人同意的正面、左右斜侧及侧面照片，选择自然光、无美颜、无遮挡素材。
2. 比较候选重建方案：多视角一致性、脸部相似度、头皮估计、推理成本、商用许可与依赖许可。不能把只有面部关键点的结果当作完整头部。
3. 独立输出标准 GLB 头模；建立统一尺寸、坐标和发际线锚点，再接入现有展示层。
4. 用 3 位不同脸型测试者验证：正侧脸可辨识、耳额无明显穿模、后脑形状合理。记录失败案例与每次生成时间、成本。
5. 用真实授权发型资产替换几何轮廓，验证完成后再采购更多素材或部署付费服务。

重建接口建议：POST /api/reconstructions 创建任务；GET /api/reconstructions/{id} 查询状态；成功时返回 GLB 地址、处理耗时和估计区域说明。当前未开放这些接口，也没有模拟“生成成功”。未来接入上传前必须补上数据保留、授权和删除机制。
